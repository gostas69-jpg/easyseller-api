# Обновления

Здесь все версии библиотеки: номер, дата выхода и что изменилось. Новые сверху. Номер версии по правилам
[семантического версионирования](https://semver.org/lang/ru/): первая цифра меняется, когда старый код сайта
придётся поправить, вторая, когда появилось новое и ничего не ломается, третья, когда исправлена ошибка.

Обновиться: `composer update easyseller/site-sdk`.

Изменения самого протокола EasySeller (новые поля, новые виды изменений) описаны в его журнале изменений,
глава 9 описания протокола. Библиотека поддерживает протокол версии 2.

## 1.0.0 · 20.11.2026

Первая версия.

- Клиент API EasySeller: ключ API, ошибки протокола, «повторите через N секунд». Запросы через curl, без него
  через потоки PHP.
- Отправка данных сайта: товары, заказы, склады, остатки, справочник характеристик и сведения о сайте. Пачками до
  200 строк и 1 МБ, итог по строке, отметка `through` по заказам.
- Очередь отправок: повторы через 1, 5, 15, 60 минут, дальше раз в час, сутки; сверка раз в час; сведения о сайте
  раз в сутки.
- Изменения из EasySeller: забор `GET /changes`, применение один раз по номеру, ответ результатами. Обработчик по
  видам: правка карточки, цена, остаток, склад, отмена заказа, «товар пришёл». Просьбу прислать данные заново
  библиотека выполняет сама.
- Вебхук с изменениями: применяет изменения только с адресов EasySeller (`webhook_ips`), отвечает результатами.
- Печатные формы заказа: штрихкоды мест СДЭК в PDF.
- Готовое хранилище на PDO: MySQL, MariaDB, SQLite.
